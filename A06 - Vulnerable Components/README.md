# 📦 A06: Vulnerable and Outdated Components

---

## 📌 1. Definition (التعريف)

> **هو فشل النظام في تحديث المكونات التي يعتمد عليها، مثل المكتبات أو إطارات عمل أو البرامج الخارجية، واستخدام نسخ قديمة تحتوي على ثغرات معروفة أو أنها توقفت عن تلقي التحديثات الأمنية، مما يسمح للمهاجم باستغلالها بسهولة.**
---

## 🧩 2. Types (أنواع الثغرة)

- **مكتبة قديمة بها ثغرة معروفة (Known Vulnerability in Old Library)**: مثل ثغرة Log4Shell في مكتبة Log4j.
    
- **إطار عمل منتهي الدعم (EOL Framework)**: استخدام إطار عمل مثل AngularJS أو Django نسخ قديمة لم تعد تتلقى تحديثات أمنية.
    
- **نظام تشغيل قديم (Outdated OS)**: استخدام Windows Server 2012 أو CentOS 6 التي توقفت عن تلقي التحديثات.
    
- **سيرفر ويب قديم (Old Web Server)**: إصدارات قديمة من Apache أو Nginx أو IIS تحتوي على ثغرات معروفة.
    
- **عدم تطبيق التحديثات الأمنية (Missing Security Patches)**: وجود تحديث أمني لثغرة خطيرة ولكن لم يتم تثبيته.
    
- **مكتبة غير موقعة أو من مصدر غير موثوق (Unsigned Library)**: تحميل مكتبة من مصدر غير رسمي بدون التحقق من صحتها.
    
- **مكونات من طرف ثالث غير مدققة (Unvetted Third-Party Components)**: استخدام مكتبات أو أدوات بدون فحص أمني مسبق.
---

## 🛡️ 4. How to Prevent (كيف تمنعها)

- **تحديث المكونات بشكل مستمر:** قم بتحديث المكتبات والأطر وأنظمة التشغيل إلى أحدث الإصدارات الآمنة، خاصة عند وجود ثغرات خطيرة.
    
- **استخدام أدوات فحص الثغرات:** استخدم أدوات مثل `OWASP Dependency-Check` أو `Snyk` أو `Retire.js` لاكتشاف المكونات القديمة أو التي بها ثغرات.
    
- **مراقبة قواعد بيانات الثغرات (CVE):** تابع مواقع مثل `CVE Details` أو `NVD` لتعرف أي ثغرات جديدة تظهر في المكونات التي تستخدمها.
    
- **تجنب المكونات منتهية الدعم (EOL):** لا تستخدم مكتبات أو أطر عمل توقفت عن تلقي التحديثات الأمنية، مثل AngularJS القديم أو Python 2.
    
- **استخدام المصادر الرسمية فقط:** لا تحمل المكتبات من GitHub شخصي أو مواقع غير رسمية؛ استخدم المصادر الموثوقة مثل NPM الرسمي أو Maven Central.
    
- **إزالة المكونات غير المستخدمة:** احذف أي مكتبات أو أدوات لم تعد تستخدمها في المشروع، حتى لا تصبح هدفاً للمهاجم بدون فائدة.
    
- **تفعيل التنبيهات الأمنية:** اشترك في التنبيهات الأمنية للمكتبات التي تعتمد عليها، عشان تعرف فوراً إذا ظهرت ثغرة جديدة.
---

## 🧠 Attacker Mindset (كيف تفكر كمخترق؟)

- **هل الموقع يستخدم مكتبات قديمة؟** كيف أعرف إصدار jQuery من الرابط (مثل `jquery-3.5.1.min.js`)?
- **هل هذا الإصدار فيه ثغرات معروفة؟** كيف أبحث في CVE Details؟
- **هل فيه إطار عمل منتهي الدعم؟** كيف أستغل ثغرات قديمة ما تم تصحيحها؟
