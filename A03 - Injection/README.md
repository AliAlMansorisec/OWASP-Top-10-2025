# 💉 A03: Injection

---
## 📌 1. Definition (التعريف)

> **هو فشل النظام في تنقية أو التحقق من المدخلات القادمة من المستخدم، مما يسمح للمهاجم بإرسال أوامر أو استعلامات ضارة إلى النظام لتُنفذ بدون إذن، مثل حقن SQL أو أوامر النظام.**
---

## 🧩 2. Types (أنواع الثغرة)

- **حقن SQL (SQL Injection)**: حقن أوامر SQL لتجاوز تسجيل الدخول أو سحب البيانات من قاعدة البيانات.
    
- **حقن الأوامر (Command Injection)**: حقن أوامر نظام (مثل `ping` أو `ls` أو `dir`) لتنفيذها على السيرفر.
    
- **حقن NoSQL (NoSQL Injection)**: استغلال قواعد البيانات غير العلائقية مثل MongoDB.
    
- **حقن LDAP (LDAP Injection)**: حقن أوامر في نظام المصادقة LDAP.
    
- **حقن XML (XXE - XML External Entity)**: حقن كود XML لقراءة ملفات السيرفر الداخلية.
    
- **حقن XSS (Cross-Site Scripting)**: حقن أكواد JavaScript ضارة في صفحات الويب لتنفيذها على متصفح الضحية، وتنقسم إلى:
    
    - **مخزنة (Stored)**: الكود الضار يحفظ في قاعدة البيانات وينفذ كلما زار الضحية الصفحة.
        
    - **معكوسة (Reflected)**: الكود الضار يرسل عبر الرابط وينفذ مرة واحدة.
        
    - **قائمة على DOM (DOM-based)**: الكود الضار ينفذ من خلال معالجة DOM في المتصفح بدون وصول للسيرفر.
---

## 🛡️ 4. How to Prevent (كيف تمنعها)

- **استخدام الاستعلامات المعلمة (Parameterized Queries):** استخدم Prepared Statements في SQL بدلاً من دمج المدخلات مع الاستعلام مباشرة (مثل PDO في PHP أو PreparedStatement في Java).
    
- **تنقية المدخلات (Input Validation):** قم بتحديد قائمة بيضاء (Whitelist) للقيم المسموح بها، ورفض أي مدخلات لا تطابق التنسيق المطلوب.
    
- **تشفير المخرجات (Output Encoding):** قم بتشفير البيانات قبل عرضها في المتصفح لمنع XSS، مثل استخدام `htmlspecialchars` في PHP أو libraries مخصصة.
    
- **استخدام ORM (Object Relational Mapping):** استخدام أطر عمل مثل Entity Framework أو Hibernate أو Eloquent، والتي تتعامل مع الاستعلامات بشكل آمن تلقائياً.
    
- **تقليل صلاحيات قاعدة البيانات:** لا تستخدم حساب `root` أو `sa` في التطبيق؛ استخدم حساب بصلاحيات محدودة (مثل SELECT, INSERT فقط).
    
- **استخدام أدوات فحص الثغرات:** قم بتشغيل أدوات مثل `sqlmap` بشكل دوري لاختبار وجود ثغرات الحقن، أو استخدم SAST في مرحلة التطوير.
---

## 🧠 Attacker Mindset (كيف تفكر كمخترق؟)

- **هل أي خانة تاخذ مني مدخلات وتتعامل مع قاعدة بيانات؟** كيف أجرب علامة اقتباس واحدة `'` عشان أشوف إذا يطلع لي خطأ SQL؟
- **هل أي خانة تاخذ مني مدخلات وتنفذ أوامر نظام؟** كيف أجرب `; ls` أو `| ping` عشان أشوف إذا الأمر ينفذ؟
- **هل أي خانة ترجع بياناتي بدون تنقية؟** كيف أحقن `<script>` عشان أختبر XSS؟
